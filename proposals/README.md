# Proposals

Numbered proposals to change the Jinn protocol specification. The process is in [`GOVERNANCE.md`](../GOVERNANCE.md).

A proposal is the permanent record of why a rule is the way it is. It is never deleted, whatever its ruling.

## Statuses

- **draft**: opened, no sponsor yet.
- **sponsored**: a maintainer has taken it up; it is in the queue to be ruled.
- **accepted**: ruled in favor; an implementing change follows.
- **rejected**: ruled against; the rationale stays.
- **withdrawn**: the author withdrew it.
- **superseded**: replaced by a later proposal, named in the header.
