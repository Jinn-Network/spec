# 0000: Template

## Problem

What is wrong or missing today, for whom, and how it shows up. Cite the document and section. If two implementations disagree, say what each does.

## Change

Exactly what changes, document by document. For a sealed document, the name of the new document that supersedes it and the new identifier.

## Effect on existing records and implementations

Which records already in the world are affected and how a reader treats them afterward. Which implementations must change and what they must do. If nothing breaks, say so and say why.

## Vectors

The vectors added or the errata appended, and what each proves.

## Rationale

Why this change and not the alternatives. Name the alternatives considered and why each was set aside. This section is the permanent record; write it for someone reading it in five years.

## Ruling

Filled in by the sponsoring maintainer: the ruling, the date, and one sentence of reason.
